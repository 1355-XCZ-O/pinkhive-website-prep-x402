# Claude Ship Guard — free sample

This runnable sample contains the dependency-free commit-message checker used
by PinkHive's customized Ship Guard generator.

```shell
python commit_message_lint.py "add payment retry"
python commit_message_lint.py "wip"
```

The first command exits 0; the second exits 1. The paid x402 unit generates a
project-specific `/ship` command, scoped PreToolUse credential scanner,
settings, manifest, deterministic ZIP, file inventory, and SHA-256 receipt.

Paid endpoint:
https://pinkhive-website-prep-x402.onrender.com/v1/claude-ship-guard
